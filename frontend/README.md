#  SoundBloom

**SoundBloom** is a sleek and minimalistic music web project built with **React**, hosted via **GitHub Pages**.  
Explore a modern, responsive interface designed for listening to (and soon uploading) tracks.

🌍 **Live Demo:** [SoundBloom on GitHub Pages](https://rikotx.github.io/SoundBloom/)

---

##  Features
-  Clean, minimalist design with manual CSS styling (no CSS frameworks used)
-  Fast and responsive UI for seamless listening experience
-  Conceptual features such as playlists and track organization
-  Future vision:
  - User registration & authentication
  - Uploading tracks & creating personal playlists
  - Backend integration and database support

---

##  Tech Stack
- **React** — for building a dynamic UI
- **CSS / custom styling** — handcrafted styles for a polished look
- **GitHub Pages** — for easy and free deployment
